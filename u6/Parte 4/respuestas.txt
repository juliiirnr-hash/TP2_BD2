Script de validación e integridad estructural (Conteo de filas):
Una vez conectado a la base de datos de prueba (foodstore_restore_test), se ejecutó el siguiente script SQL para contrastar y verificar la cantidad de registros recuperados por tabla, obteniendo totales consistentes:   
SQL
SELECT 'categoria' AS tabla, COUNT(*) AS filas FROM categoria
UNION ALL SELECT 'usuario', COUNT(*) FROM usuario
UNION ALL SELECT 'producto', COUNT(*) FROM producto
UNION ALL SELECT 'pedido', COUNT(*) FROM pedido
UNION ALL SELECT 'detalle_pedido', COUNT(*) FROM detalle_pedido;
```[cite: 4]
*Resultados obtenidos:*

 `usuario`: 20, 
`producto`: 50,

Script de validación de restricciones lógicas de negocio:
Se ejecutó el script de control sobre los valores críticos para certificar la sanidad y consistencia de los datos restaurados:   
SQL
wSELECT COUNT(*) AS productos_invalidos
FROM producto
WHERE precio < 0 OR stock < 0;

SELECT COUNT(*) AS detalles_invalidos
FROM detalle_pedido

```[cite: 4]
