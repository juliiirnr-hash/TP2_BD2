Parte 2: Respaldo automatizable
-Implementación del script: Se desarrolló y configuró el script de automatización en PowerShell bajo el nombre backup_foodstore.ps1
-Comando y formato de respaldo: El script automatiza la extracción lógica de la base de datos utilizando la herramienta pg_dump con el formato personalizado (-Fc), lo cual permite generar respaldos consistentes y optimizados para restauraciones selectivas.   
-Nombre dinámico con fecha y hora: Para garantizar la trazabilidad y evitar la sobrescritura, el script genera automáticamente el archivo de respaldo incluyendo de forma dinámica la fecha y la hora exacta del proceso (por ejemplo, food_store_test_20261029_0952.dump), acompañado de su respectiva huella digital de integridad (.sha256).   
Seguridad y control de errores: Se cumplió estrictamente con la política de seguridad de no incluir contraseñas en texto plano dentro del código del script.   El procedimiento se conecta mediante un rol de mantenimiento con privilegios específicos (mant_backup).   Se configuró el registro de eventos en una carpeta de logs dedicada y un mecanismo de validación para finalizar con error en caso de que pg_dump falle.
-Prueba manual previa: Antes de considerar el script apto para su programación en el sistema operativo, se ejecutó de forma manual en la terminal de PowerShell, verificando con éxito la correcta creación de los archivos de salida y los registros.
